# Retro Computer Collection — Web Edition

A read-only, static-website mirror of the iOS app **Retro Computer Collection**
(app ID 6763369439, bundle `com.craicdesign.Computers`). Browse the same
specifications, stories, sample programs, popular games, emulator links,
peripheral notes, and photo galleries for **113 legendary home computers** —
no iPhone required.

Hosted at: https://GrantMeStrength.github.io/RetroComputerFacts/

## Tech

Static HTML + CSS + vanilla JS. No build step, no framework, no server.

| Path | Purpose |
| --- | --- |
| `index.html` | Single-page shell |
| `css/style.css` | Retro / CRT-inspired theme (phosphor-green + per-category accents) |
| `js/app.js` | Hash-routed SPA — home grid with search/filter/sort, and detail view per computer |
| `data/computers.json` | Full facts payload — extracted byte-for-byte from the iOS app's Swift source |
| `data/asset-map.json` | Maps asset names (referenced by the data) to the WebP image files |
| `data/assets/` | 160 optimised WebP images (156 MB original → ~12 MB WebP) |

## Local preview

Just open `index.html` in a browser — or serve for nicer devtools:

```bash
cd RetroComputerFacts
python3 -m http.server 8000
# → http://localhost:8000
```

## Deployment

GitHub Pages, **Deploy from a branch → `/main` → `/ (root)`**. Enable under
*Settings → Pages*. No build step required.

## Data provenance

`data/computers.json` is generated by `/Users/john/Developer/Computers/extract_facts.py`.
That script assembles the real iOS `ComputerType` + `ComputerCatalog` Swift
sources into a Foundation-only program, runs it with `swift`, and serialises
every machine's `overview`, specs, `keyFeatures`, `historicalNotes`,
`samplePrograms`, `peripherals`, `popularGames`, `emulatorLinks`,
`communityResources`, and `photos`.

Regenerating after app changes:

```bash
cd /Users/john/Developer/Computers
python3 extract_facts.py /path/to/RetroComputerFacts/data/computers.json
# then run the image-map + re-optimisation snippet in js/ if the asset set changed
```
